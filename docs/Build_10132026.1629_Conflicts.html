Compatibility and safeguards

FORMAT CHANGE · SCHEMA 2

New artwork needs a richer project format

New files use schema 2 for contours, centerlines, shapes, text, textures and typed layers. Schema 1 files open through an in-memory migration: ordinary layers become Vector; legacy imported-image layers become Bitmap. Source files remain unchanged until Save. Earlier builds reject schema 2 files safely; retain earlier copies when testing. The application major version remains 1.

BITMAP EDITING LIMIT

Pixel editing is limited to 16 megapixels per project canvas

Bitmap stroke commits, flattening and selections support canvases up to 16 megapixels, including standard 4K. Larger canvases continue to support Vector drawing. Requests exceeding the Bitmap limit show a message and preserve the original layer. Bitmap strokes/text/shapes flatten on commit; they cannot subsequently expose Vector control points. Undo can restore earlier states.

FILL RESOLUTION

Bucket boundaries use a bounded working grid

Flood fill and gap closing use a grid up to 2048 pixels on the longest side. Vector fills store the traced boundary in project coordinates, with holes retained; Bitmap fills flatten. Tiny gaps or details in larger projects can depend on this working resolution. Gap closing does not rewrite the underlying lines.

RESOLVED · ROTATED DRAWING VIEW

Input coordinates follow the view transform

Drawing, selection and camera handles use inverse screen transforms so pan, zoom and view rotation do not move the authored coordinates unexpectedly. Holding Space temporarily pans in Drawing view and restores the chosen tool on release. Timeline and Pitch retain their playback shortcut.

RESOLVED · LAYER ISOLATION

Selections and erasing respect locks and visibility

Selection scope can include all visible, unlocked layers. Hidden and locked layers cannot be modified through drawing selections. Eraser strokes target the active layer; bitmap regions flatten after committed transforms. Vector erasing preserves the underlying geometry with mask strokes.

EXISTING CAMERA SAFEGUARDS

Camera-keyed panel membership remains protected

The previous camera safeguards remain: individual panel transfers/deletion within camera-keyed scenes are blocked; whole-scene moves preserve their track. No audio or PDF milestone behavior is added here.

Preview build refresh

The launcher now compares a generated build stamp with the current version/build metadata. Updating an existing checkout rebuilds stale preview assets instead of silently displaying an older build. Missing dependencies are installed as before.

Options and validation

Tools include Select (individual/rectangle/lasso), Brush, Pencil, Contour Editor, Pencil Editor, Text, Eraser, Bucket, Rectangle/Ellipse/Line, Color Picker, Hand, Rotate View and Vector Select by Color. Built-in Solid/Graphite/Chalk textures and device-local presets are supported; custom texture/font import is outside this build. System font availability determines text appearance.
