Resolved issues

TEXT SELECTION BOUNDS

Estimated text widths did not match rendered glyphs

Selection bounds now measure the same font used for drawing, including tracking, indentation, multiline content, horizontal scaling and rotation. Existing text objects are covered without modifying their artwork or requiring recreation.

CAMERA KEY IDENTITY

Dragging a sampled endpoint pose could copy its key ID

The camera sampler can return a key object at or beyond an endpoint. Copying the entire dragged pose into a newly created key could overwrite its generated ID and requested frame with that endpoint’s metadata. This was an application defect, not a user error. Camera key creation now accepts only pose/interpolation values and owns its ID/frame. Previously rejected edits left the project unchanged.

DRAWING PANEL SHORTCUTS

Duplicate and Delete are available beside the existing panel buttons

The Drawing strip shares the inspector’s panel actions, including undo, confirmation, unique duplicated artwork IDs, camera timing and existing deletion safeguards. Other workspace strips are unchanged.

Camera workflow

  1. Select Camera (C), then Set scene IN / OUT.
  2. Select a key time; adjust X/Y, zoom, rotation and interpolation.
  3. Drag green/red centers to pan or corner squares to zoom in Drawing view. Preview in Timeline or Pitch.

Individual panel deletion/transfers in camera-keyed scenes remain guarded. Clear the scene keys first or move the whole scene to preserve its track. The schema 2 compatibility and Bitmap/fill limits documented in the previous build still apply.
