Findings and corrections

  • Live smoothing previously replaced the current endpoint with a point partway toward the cursor. At higher zoom this visible gap increases. The latest endpoint now remains exactly at the pointer; smoothing adjusts earlier samples.
  • Round contour caps swept inward. Their sweep is corrected so new brush and variable-pressure contours extend outward around their endpoints.
  • Brush contour rendering used even-odd fill, which cancels paint in self-overlapping regions. Brush contours now use nonzero winding, with matching selection hit testing. Bucket-fill objects retain even-odd fill to preserve intended holes.

Validation

Production build, 35 model/filesystem tests, all eight earlier browser workflows and the new drawing regression pass. The regression checks live and committed Brush/Pencil endpoints on Vector and Bitmap layers at 100%, 150%, 200% and 300%; persisted coordinates; self-crossing opacity; bucket holes; variable-pressure Pencil; and drawing after pan/rotation. Coordinate transforms were correct in the test browser across these zoom levels; no unsupported browser-specific offset fix was introduced.

Existing artwork and scope

The overlap rendering correction applies to editable brush contours already in projects. Existing contour geometry is retained; old round caps are not regenerated, because that could overwrite Contour Editor changes. Already flattened Bitmap pixels cannot be reconstructed automatically. New Bitmap strokes benefit from the corrected drawing/rendering path.
