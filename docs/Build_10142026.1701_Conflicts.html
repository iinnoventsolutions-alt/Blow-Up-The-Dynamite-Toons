IInnovent Professional Storyboard · Working · Zoom origin and Pencil Editor follow-up

Drawing coordinates

  • Drawing input is now mapped against the painted canvas rectangle, accounting for scale, pan and rotation. It no longer depends on the drawing SVG's screen transformation matrix.
  • Pointer-down focuses the interaction surface without scrolling, then computes the position. The interaction SVG stretches to match the painted canvas without aspect-ratio letterboxing.
  • Brush, Pencil, drawing selection, point editors, fill/picker and double-click editing use the same canvas-based coordinates.
  • The prior brush overlap and smoothing fixes remain intact.
The user’s sequence—draw at 100%, zoom to 175%, draw again—did not reproduce the reported offset in the test browser before this follow-up. This build removes two potential sources of browser-specific mismatch: SVG matrix dependence and focus scrolling. The exact sequence is now a regression test, including a deliberately stale SVG matrix. Confirmation on the user's Mac remains necessary; a browser-only pass is not proof of native reproduction.

Pencil Editor

Choose Pencil Editor and click a Vector Pencil stroke. Square handles edit existing centerline points; hollow circles between them can be dragged to insert and position a new control point. Double-clicking a segment remains an alternative. Delete removes the selected point; Undo restores the edit.

  • Point moves retain the original pressure/width value rather than replacing it with mouse pressure.
  • Double-clicking a handle does not insert a duplicate extra point.
  • Tool properties explain the editing workflow. Clicking Brush artwork with Pencil Editor explains that it needs Contour Editor. Bitmap artwork has no vector spine and requires pixel selection.

Validation

Production build, 36 model/filesystem tests and ten browser workflows pass. The new browser workflow uses a 2× display scale. New checks cover the exact 100→175% sequence for Brush/Pencil on Vector/Bitmap layers; stroke origin and saved coordinates; independence from a stale SVG matrix; unchanged stage position during focus; and Pencil Editor selection, dragging, midpoint insertion, double-click insertion, deletion, undo, save/reopen and pressure preservation.

Coordinate math is also checked across portrait, landscape and unusual aspect ratios, fractional zoom, translation and several rotations. Earlier camera, text, transitions, onion skins, fill, drawing, panel and timeline regressions pass.
