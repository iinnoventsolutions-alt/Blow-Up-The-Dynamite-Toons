How to review this build

  1. Open a project and click Export PDF in the header. The desktop File menu also has Export PDF.
  2. Select 3 Panels Vertical, keep the cover enabled and use Preview PDF. Export and compare the stacked rows with the supplied example.
  3. Try a long dialogue, hidden layer, camera move and scene boundary. Check the final caption lines, camera frames, logos and page numbers.
  4. Try the other templates, ranges and a custom company logo. Save a profile, close/reopen the dialog, and select that profile again.
  5. On the Mac desktop build, confirm Save cancellation, a custom save destination and Open document after export. The browser version downloads through normal browser settings.

Conflicts, reference differences and practical limits

No blocking data-model, audio-timing or project compatibility conflicts found.

This is a reference-inspired implementation, not a pixel-for-pixel copy of the older application's PDF engine. These differences are explicit so the review can focus on the output you need.
  • The sample uses a slightly custom 612.283 × 790.866 pt page. Standard Letter is 612 × 792 pt; A4 is also provided. Typography uses an embedded readable sans font rather than the example's Courier.
  • The legacy screenshots show password/permission protection and tracked panels. Those controls, custom page backgrounds, arbitrary paper sizes and legacy XML profile import are not implemented in this delivery. No inactive controls imply otherwise.
  • Long captions add continuation slots and can increase page count, especially in Overview. Disable captions for a compact visual overview. Long header names are shortened with an ellipsis; full project title/subtitle appear on the cover.
  • Captions are selectable PDF text. The embedded font supports common Latin/Greek/Cyrillic text but not every script/emoji. Missing glyphs stop export with a clear message. Artwork text remains rasterized with the artwork.
  • Artwork renders at 150/300 DPI with a 4096-pixel edge cap. It remains a raster image in the PDF. Hidden layers stay hidden; editing handles, onion skins, audio waveforms and live transition blending are excluded. Transitions appear as text descriptions.
  • Exports are limited to 500 pages and 128 MB. Large projects should use smaller ranges or lower DPI. Rendering yields between slots and can be cancelled.
  • Profiles and custom logos are device-local; they are not shared inside .issb files. Save profile is required to persist edits.
  • Embedded PDF preview depends on the browser/desktop PDF viewer. If unavailable, export and open in a PDF reader. Actual Mac dialogs, PDF plugin behavior and default-reader opening require hardware review.
