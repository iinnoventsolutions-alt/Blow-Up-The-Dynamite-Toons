Changes in this build

  • Categorized Preferences: General, Drawing, Naming, Import / Export, Pitch, Shortcuts. Legacy device settings migrate; Done keeps changes, Cancel/Escape/close restores the opening values.
  • New-item defaults: resolution/frame rate, Vector/Bitmap layers, selection mode, bucket gap, Scene/Panel number padding and scene increments. No automatic edits to existing project names, timing or artwork.
  • Optional module restoration, audio-track deletion warning, Pitch caption display and recovery-in-Pitch settings. Existing defaults retain the prior behavior.
  • PNG longest-edge limit preserves aspect ratio. Image import validates file signature and decode success before adding a layer; invalid imports leave the project unchanged. Input limits are 8 MB and 16 megapixels.
  • Camera-aware panel move/copy/delete replaces the old blanket restriction on keyed scenes. Drawings, layers, notes and camera motion travel together. Audio stays anchored to project time.
  • Pitch full screen targets the presentation stage and transport. The caption toggle is optional; Timeline audio mixing remains unchanged.

Camera and audio policy

Before a structural edit, each affected panel’s camera motion is read from its original scene. Original keys inside that panel travel with it; sampled start/end poses isolate the panel from its new neighbors. Panels from unkeyed scenes retain their neutral camera framing when moved into keyed scenes. Copies receive fresh camera IDs. Whole-scene moves retain their existing camera keys.

Linear and Hold motion retain their poses. Ease segments wholly inside a panel retain the original easing keys; an ease segment clipped by a panel boundary is sampled at whole project frames so playback/export poses stay the same. Only structurally changed scenes are rebuilt. No-op moves do not alter keys.

Audio clips remain at absolute frame positions. Reorder does not ripple audio; duplication adds picture time without copying audio; deletion shortens picture time without moving sound. Audio beyond the storyboard end follows the previously documented playback/export limit.

Each structural edit is one Undo step. Removing transition adjacency still removes the affected transition with a notice; Undo restores it with the panels and camera data.

Conflicts and practical limits: Camera rebuilding can add boundary and frame-sample keys. Edits exceeding 10,000 keys in a scene reject before commit, leaving the entire project unchanged. Dense keys can trigger the existing key-collision guard when shortening panel duration; adjust/remove keys first. Deleting a scene’s last panel remains blocked. Moving panels may leave an empty scene, whose camera keys are cleared. These are deliberate constraints rather than silent camera loss.

Persistence and media audit

  • .issb projects embed image/audio sources. There are no external media paths to relink. Corrupt embedded media may still require restoring an earlier project; automatic media repair is not implemented.
  • Schema remains 4. Older schemas upgrade in memory; normal Save commits the new schema. No project format change is introduced here.
  • Browser recovery/history stays in IndexedDB; native recovery and saves retain atomic filesystem writes. Recovery is an emergency snapshot after editing stops, not automatic overwriting of a project file.
  • New/Open retains the existing unsaved-change Discard/Cancel guard. Browser tab close uses the browser warning. Native Quit retains Save/Discard/Cancel. Actual Mac OS dialogs and close/recovery behavior remain part of final integration testing.
  • PNG, PDF and WebM exports do not change the project save location. Browser Save/Save As download through browser settings; desktop Save As uses the existing native destination/filename dialog.
  • Preferences, export profiles, presets and last-workspace state remain device-local. They are not embedded in a project. New default resolution/frame rate affects creation only; existing project-specific settings stay intact.

User review steps

  1. Open Preferences. Try default naming, resolution/frame rate, layer type and selection mode. Create a project and new panels/scenes; check that existing projects are not renamed or resized. Change preferences again and use Cancel.
  2. Set PNG maximum edge and export a panel, including a portrait project. Import a valid image, then an invalid file; verify the invalid attempt adds no layer.
  3. In a keyed scene, move a panel within the scene and to another scene. Compare its camera path in Drawing, Timeline, Pitch and PDF; test Duplicate/Delete and Undo. Check that audio starts at its previous project time.
  4. Try module restoration and caption visibility. Enter/exit Pitch full screen and play synchronized audio. Test recovery after editing with recovery in Pitch enabled and disabled.
  5. Review the checklist for any deferred reference option that should be prioritized before packaging.
